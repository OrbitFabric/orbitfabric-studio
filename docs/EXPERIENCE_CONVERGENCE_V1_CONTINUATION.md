## Identity and navigation changes

`investigationSubject()` resolves the proposal from the current inspected entity. If inspection is a relation or atom, proposal is unavailable; it never falls back to the old selected entity. With no inspection, the explicitly labelled native selection can be proposed. The panel shows both identities when distinct. Following an Inspector endpoint changes inspection only. Clicking **Investigate inspected subject** explicitly changes Anchor, retaining Scope, question and independently admitted observations.

Native navigation callbacks now explicitly inspect the requested entity even when it equals the existing native selection. The native reducer, context-path models and Core contracts are unchanged. X-Ray relationship following retains its existing context-path rules. Subject Return restores inspection, not native selection or investigation Anchor. This distinction is visible rather than silently conflated.

Inspection history is generation-qualified. `advanceInspection()` discards prior-generation history before admitting a new target. Existing generation-keyed InvestigationPanel and presentation memory invalidate population, Scope, Anchor, Return checkpoints and camera/drag state on Mission replacement. Native selection and all Core hydration remain product-owned.

Graph IDs use lossless JSON domain/ID tuples at the React Flow boundary; Core's NUL-delimited map keys remain internal. Controlled graph nodes retain measured dimensions, preventing React Flow from discarding handle bounds on selection updates. Relation geometry is not recomputed because of selection or camera changes.
